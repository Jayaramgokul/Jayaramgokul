### Hi, I'm Jayaram 👋

I validate and build AI and quantitative models for financial services, in London.

My day job is independent model validation and AI governance: testing whether
models, including LLM-based ones, do what they claim, and whether a regulator
would agree. On the side I build AI tools, and I try to hold them to the same
standard: **use the model for judgement, then make the code check it.**

**Featured work**

| Project | What it shows |
|---|---|
| [**validation-mcp**](https://github.com/Jayaramgokul/validation-mcp) | An MCP server that lets Claude validate a credit model, then refuses to save the report if it contains any number the code did not compute. Includes stability selection from my BSc thesis. 8 tools, 34 tests. |
| [**jobpipe**](https://github.com/Jayaramgokul/jobpipe) | An MCP server that lets Claude run a job-search pipeline. Every score the model gives must quote the job ad, and the server verifies the quote before the score counts. 11 tools, 30 tests, checked on 499 live postings. |
| [**advice-guardrails**](https://github.com/Jayaramgokul/advice-guardrails) | A red-team test for an AI financial adviser: 180 hand-written attacks, a quote-verified LLM judge, and failure rates reported with honest confidence intervals. Harness complete; first model run in progress. |
| [**career-agent**](https://github.com/Jayaramgokul/career-agent) | CV in, ranked brief of live jobs out. Claude plans the search and scores each role; Python merges cross-posts and clamps the model's scores to the rubric. Streamlit UI or headless. |
| [**credit-pd-validation**](https://github.com/Jayaramgokul/credit-pd-validation) | A credit PD scorecard plus a full independent validation (discrimination, calibration, stability, benchmarking), with the report generated by code. It finds that my own 2023 model got the default rate wrong by a factor of two. |
